# Hex Strata / Hex Genart

Hexの一局を、一枚の地層にするローカルブラウザ試作です。接続ポテンシャルの等高線を薄く積み重ね、過去の有望経路や阻まれた道の痕跡を残します。等高線を初期表示とし、電流による比較モードも備えています。

## 開き方

Node.js 22以上とPython 3の標準ライブラリを使います。npm/pipの追加依存はありません。

```sh
python scripts/fetch-selected.py
node scripts/build-records.cjs
```

取得元の利用条件を確認したうえで実行してください。8局を取得・ハッシュ検証した後、`index.html` をブラウザで開きます。サーバーは不要で、以後の描画・再生・保存はオフラインで動作します。ブラウザが直接ダウンロードする方式ではありません。

- 棋譜選択、一手ずつ／自動再生、全局積層と現在局面の切替
- 履歴濃度、線密度、実際の石表示（空きセルの補助点なし）
- SVGとSVGの2倍解像度のPNGの保存
- 等高線と、両岸間の電流による比較

## 棋譜の扱い

[Hex SGF GM[11]](https://www.red-bean.com/sgf/hex.html)を読み、分岐は最初の子を主譜として扱います。投了・forfeit・IPで停止し、投了局に勝者の経路を追加しません。盤外、重複着手、不正な手番、完成連結後の着手などを検証します。

`swap-pieces` は石の色交換と座標転置 `(x,y) → (y,x)`、次は黒です。`swap-sides` は石を保ち、次は白です。Little Golemの元SGFは公式表示との対応を確認した専用アダプターを使い、着手キーW/Bだけを交換します。PB/PW/REは保持し、二文字座標とswapをHex SGF形式に変換します。取得する公式対局ページの全表示着手とも照合できます。

## 等高線

Hexの6近傍を抵抗網にします。対象色の石は0.04、空点は1、相手石は2000の抵抗。辺コンダクタンスは `2/(r_i+r_j)`、両岸への接触は `2/r_i`、両岸の電位は1と0です。共役勾配法で電位を求め、三角格子上で等高線を抽出・曲線化します。相手石への微小漏れと曲線補間は視覚モデル上の近似です。

同じ局面の二色には同じ不透明度を使い、過去の層を保持します。投了による同一局面は重ねません。濃い線は勝率や実際の連結を意味しません。

## 電流比較

電流モードでは相手石を完全に除去した別の回路を解きます。自石0.04、空点1の有限抵抗なので、石の連結が完成しても電流は発散しません。辺電流 `I=g(Va−Vb)` を、電位が下がる方向の両岸間経路へ分解します。この分解は一意ではありません。角を丸め、経路を最大3 SVGピクセルだけ並行配置しますが、通るセルと電流量は変えません。

盤全体の通りやすさは、空盤のコンダクタンスG0を基準とするG/G0です。局所の流線幅は `2×asinh(n×I_route/G0)`。二色・全手順で共通尺度とし、弱い側を独立に拡大しません。線密度は表示経路数を変え、表示した電流の割合を併記します。省略分も全体Gに含めます。推移図は二色共通のlog(1+G/G0)軸です。

実際の石連結は別のBFSで判定します。空点経由の流れは潜在経路であり、その空点を確保できる保証ではありません。遮断された色は電流0ですが、積層では以前の流れが残ります。勝率・最善手・仮想接続やパーコレーションによる厳密な勝ち判定ではありません。

## 検証

```sh
node --test tests/*.test.cjs
node scripts/browser-check.cjs
node scripts/current-browser-check.cjs
```

データ未取得時はデータ依存の検証だけをskipし、SGF・回路モデルの単体検証は実行できます。ブラウザ検証には8局取得後のChromeが必要です。Windowsの標準Chrome配置を既定とし、ほかの環境では `CHROME_PATH` を指定してください。独立したヘッドレスプロファイルを使い、ユーザーのブラウザ画面は操作しません。

取得後は24テストで、8局915局面・各モデル1,830回の計算を確認します。鎖・並列路・空点の橋・完全遮断・孤立領域、電流保存、辺電流の経路からの復元も含みます。ブラウザ検証は等高線18項目と電流16項目。出力はローカルの `outputs/` に保存します。

## 構成

- `src/core.js`, `src/art.js`: SGF再生、実連結、電位と等高線
- `src/current.js`, `src/current-art.js`: 電流ソルバー、経路分解と描画
- `src/app.js`, `index.html`, `style.css`: 操作画面
- `scripts/fetch-selected.py`, `scripts/build-records.cjs`: 出典からのローカル再現
- `data/sources.json`: 原本を含まない取得先と検証用メタデータ

この公開用履歴には、ローカル調査用の棋譜コーパス・HTMLアーカイブ・SQLite・Library識別子・PC固有パス・画面検証画像を含めていません。

## 画像出力の範囲

PNG／SVGには中央アートと右上の棋譜概要（日付・盤サイズ・対局名・手順）のみを含めます。画面上のタイトル、下段グラフ、凡例・注記は出力しません。概要を右上の空白へ寄せて外周余白を詰め、元の線・石・色は維持します。SVGとPNGは同一の構成で、PNGはSVGの2倍解像度です。寸法は概要の文字幅に合わせて決まります。画面の比較用情報はそのまま表示されます。

`node scripts/export-check.cjs` は等高線／電流の単層・積層を実際に書き出し、SVGとPNGの画素一致と内容・余白を確認します。成果物は `outputs/exports/` に保存します。
